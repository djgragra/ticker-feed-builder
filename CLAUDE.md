# Working on this app

This repository is built under the OnAir Garage standard, which lives in a private repository:
`djgragra/garage-hub`. At the start of every chat attach it with `add_repo` (`access: push`), then read
`CLAUDE.md`, `lifecycle.md` and `apps/STANDARD.md` there and follow them. Run `node scripts/status.mjs`
in the hub and keep this app's file `state/app-<slug>.md` up to date.

Answer the owner in Italian. Never ask for or write passwords, tokens or keys.
